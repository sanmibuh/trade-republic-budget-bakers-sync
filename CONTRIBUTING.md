# Contributing

## Issue labels

Every issue should have at least one **category/** label to indicate which area of
the project it belongs to.

| Label | Description |
|-------|-------------|
| `category/bot` | Telegram bot features |
| `category/ci` | CI/CD pipeline |
| `category/configuration` | Configuration and env vars |
| `category/notifications` | Notification system improvements |
| `category/robustness` | Reliability and error handling |
| `category/sync` | Core sync functionality |

When creating a new issue, add the matching `category/*` label. If none fits,
create a new one following the `category/<name>` convention.
